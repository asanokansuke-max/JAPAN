# サムライブルー監督 — 2030への道

サッカー日本代表の監督として、2026年10月の就任から2030年ワールドカップ優勝を目指すブラウザ用シミュレーションゲーム。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要・サーバー不要）。進行はブラウザの localStorage に自動保存されます。

1. **視察**：活動の合間に視察ポイントを使って、Jリーグの試合・高校/大学/ユース・欧州各リーグを視察。潜在能力の見積もりが正確になり、まだリストにない若手が見つかる
2. **選考**：スタッフの報告を参考に20〜26人を選ぶ。先に何人か選んでから「残りを自動選考」を押すと、選んだ選手はそのままに空いた枠だけを埋める。招集枠が満員のときに招集すると外す選手を選べる。（大会は23〜26人、GK3人以上）。招集リストでは負傷・調子（5段階）・試合勘・疲労・復帰明け・意欲・クラブでの立場を確認できる
3. **メンバー発表**：初招集・復帰・主な落選・負傷で選外が発表され、落選した人気選手のコメントや世論が動く
4. **記者会見**：状況に応じた3〜4問（選考理由、落選、負傷者、批判、目標、世代交代、過密日程、国内組など）に、強気／慎重／誠実／はぐらかすの答えで応じる。士気・世論・協会評価・選手の意欲が変わり、「優勝しか考えていない」などの公約は結果で評価される。会見後は各紙の見出しとネットの反応
5. **合宿**：3日間（大会前は4日間）のメニューを1日ずつ選ぶ（戦術・攻撃パターン・守備組織・セットプレー・紅白戦・リカバリー・若手指導・ミーティング・食事会）。合宿中の負傷、紅白戦でのアピール、口論、発熱などの出来事があり、負傷者が出れば追加招集できる
6. **作戦ボード**：ピッチ上の選手をドラッグして入れ替え、控えからピッチへ落とすと先発に。タップで選手を選び、長押しで役割の変更（例：DMF→CMF、OMF→CF）と個別指示。フォーメーションを変えても先発11人はそのまま配置し直す。試合期間中は画面下の試合バーから、どのタブにいてもキックオフや前日会見に進める
7. **戦術・セットプレー**：フォーメーション5種、メンタリティ、スタイル、先発11人。CKの形（混合・ニア・ファー・ショート）、守り方（ゾーン・マンツーマン）、CK/FK/PKキッカー
8. **試合**：1分刻みのライブ実況。一時停止すると作戦ボードで采配できる：フォーメーション変更、ドラッグでポジション入れ替え、控えをピッチへドラッグして交代（タップでも可）、長押しで役割と個別指示、メンタリティとスタイルの変更。試合後は報道とネットの反応で世論と士気が動く
9. **時間経過**：活動の合間に選手が成長・衰退し、移籍・負傷・新星の登場が起こる

## 代表運営のリアル要素

- **クラブとの交渉**：メンバー発表後、クラブから「出場は60分まで」「合流を遅らせたい（初戦欠場）」「招集を見送ってほしい（五輪）」などの要望。受けるとクラブとの関係が良くなり、断ると関係が悪化して選手のクラブでの立場にも響く
- **移動・時差・気候**：欧州組の帰国やJリーグ組の欧州遠征は時差で合宿時のコンディションが下がる。ホームとアウェーで地域をまたぐと移動疲れ。中東の酷暑・東南アジアの高温多湿では体力の消耗が15%増える（地元チームは慣れている）
- **警告の累積と規律**：公式戦は警告2枚で次戦出場停止（大会は準々決勝後にリセット、予選は2次予選と最終予選の間でリセット）。退場は次の同じ大会の試合で出場停止。合宿では門限破りやSNS騒動が起き、厳罰／注意／不問から処分を選ぶ
- **キャプテン**：主将・副主将を指名。統率力（リーダーの特徴・代表経験・年齢・連携・意欲）が高い主将が先発すると士気が上がり、合宿のもめ事が減る。主将交代や主将の落選は波紋を呼ぶ
- **二重国籍の有望株**：欧州のクラブにいる日本と他国の二重国籍の若手。視察で見つけ、電話や現地面会で説得する。相手国に呼ばれると気持ちが離れ、公式戦に出場させれば日本代表で確定
- **ロサンゼルス五輪（2028年7月）**：U-23（2005年以降生まれ）＋オーバーエイジ3人の18人。16か国、グループ→準々決勝→準決勝→決勝・3位決定戦。欧州のクラブは派遣を渋る。大舞台の経験で若手が伸び、A代表のメンバーは大会後に元に戻る
- **分析の重点**：試合ごとに「相手エースを封じる」「相手のセットプレー対策」「弱点サイドを突く」「ビルドアップ封じ」から1つ選ぶ
- **協会との面談**：大会や予選の節目に、スカウト部門の増員・合宿環境の改善・医療体制の強化・分析部門の強化・強豪国とのマッチメイクから1つを要望。評価が高いと契約延長のオファー、低いと最後通告（解任ラインが上がる）

## 試合と選手を取り巻く要素

- **FIFAランキング**：試合結果でポイントが動く（大会の重要度、相手との差で増減）。W杯本大会の抽選ポットはランキング順（開催国＋上位9か国がポット1）。アジアカップのポットも同様
- **E-1選手権（2027年・2029年7月）**：国内組（Jリーグ所属）だけで戦う東アジアの大会。国内組の見極めの場
- **選手からの相談**：移籍すべきか（背中を押すと移籍が成立）、代表引退を考えている（引き留め／若手の手本として残留／尊重）、出番がない不満（先発を約束すると守らなければ信頼を失う）
- **家族の事情**：合宿中や大会中に「妻の出産に立ち会いたい」などの申し出。許可すると一時離脱、断ると不満が残り報道されることも
- **コンビと競争**：同じクラブのチームメイトや長年のコンビが先発に並ぶと連携ボーナス。同ポジションで力の近い選手は先発争いになり、敗れた側は意欲が下がる
- **前日会見とプレッシャー**：大一番の前日会見で強気／平常心／選手を守るを選ぶ。重圧は大会のノックアウトやアウェーで大きく、代表経験の浅い選手は硬くなり、修羅場をくぐったベテランは落ち着く
- **天候・ピッチ・審判**：雨・大雨・強風・雪、荒れたピッチはポゼッションに不利。主審ごとにカードの出しやすさが違う。VARによるゴール取り消しやPK取り消し、ノーファウルの微妙な判定があり、報道でも取り上げられる
- **個別指示**：先発選手ごとに「攻撃参加を控える」「積極的に攻撃参加」「自由に動く」「プレスの先頭に立つ」「相手エースをマーク」「守備を免除」

## 駆け引きと物語

- **相手国の事情**：相手国の主力にも負傷があり、欠場すると戦力が落ちる。監督交代で戦い方が変わる。分析担当とニュースが伝える
- **戦術の研究**：同じフォーメーションとスタイルを続けると相手に研究され、相手の力が上がる（直近10試合で7試合以上同じ形）
- **ハーフタイムの声かけ**：鼓舞する／叱咤する／冷静に指示。スコアによって効果が変わり、勝っているときの叱咤は逆効果
- **交代への不満**：前半や60分前に下げられた選手は不満を持つ。性格によっては報道されるほど荒れる
- **選手の性格**：勝負強い（大舞台で力を発揮）、目立ちたがり（出番がないと不満、活躍すると乗る）、ムラがある、チームプレーヤー（控えでも腐らない）、繊細（重圧に弱い）、職人（いつも安定）
- **大会前の準備**：大会ごとにベースキャンプを選ぶ（回復の速さ、暑さへの順化、移動、合宿日数）。合宿で非公開の練習試合（強豪・格下）を組める
- **代表通算記録**：就任前の出場・得点を含めた通算記録。50・100・150試合出場や得点の節目、歴代最多得点への挑戦が報道される。節目を迎える選手は試合前に知らされる
- **観客とスタジアム**：ホームの会場と観客数（世論と相手の人気で変わる）。満員は後押しに、空席と世論の冷え込みは重圧になる
- **協会の強化予算**：勝利・世論・スポンサーで増え、強化策が承認されると使う。予算が足りないと要望は通らない
- **育成年代の世界大会**：U-17・U-20ワールドカップの結果が届き、活躍した若手が評価を上げて新星として浮上する

チームの状態は「チーム士気」「世論」「協会評価」の3つ。士気は試合の力に、世論は協会評価に影響する。

## スタッフ

代表活動のたびに4人のスタッフがレポートを持ってくる（「スタッフ」タブ）。

- **ヘッドコーチ**：クラブでの状態（調子・試合勘・立場・負傷明け）を踏まえた招集案と、前回メンバーからの入れ替え提案。大会中は疲れた先発のローテーション案
- **チーフスカウト**：好調な未招集選手、有望な若手（推薦時に潜在能力の見積もりが正確になる）、未招集の海外組、Jリーグ組
- **チームドクター**：負傷者の診断と復帰見込み、復帰明けの再発リスク、過密日程による疲労
- **分析担当**：対戦相手のフォーメーション・戦い方・警戒選手と、それに対する推奨作戦（そのまま適用できる）

## クラブ事情

- 選手ごとに今季のクラブ成績（出場・先発・得点・アシスト・平均評価）を月単位でシミュレーション。欧州は8〜5月、Jリーグは2〜12月のシーズン
- 試合勘：クラブでの出場時間で上下し、合宿時のコンディションと成長に影響
- クラブの調子、CL出場（試合数が増え疲労）、監督交代（序列が入れ替わる）、同ポジションの補強、ライバルの離脱
- 移籍は噂（5〜6月・11〜12月）を経て移籍市場（8月・1月）で成立または破談
- 負傷は14種類（肉離れ、捻挫、前十字靭帯断裂など）で週単位の離脱期間。同じ部位の再発、復帰直後の再負傷リスク、大けがからの復帰後の能力低下あり

## 仕組み

- **選手の成長**：年齢・潜在能力との差・所属クラブの格・クラブでの立場（レギュラー／準主力／控え）で毎月変動。若手は上位クラブでレギュラーになると伸び、控えが続くと停滞する。30歳前後から衰える
- **移籍**：夏と冬の移籍市場で、活躍した選手はステップアップ、出場機会のない選手は移籍や国内復帰
- **潜在能力の見積もり**：視察ポイントを使うか代表に招集すると正確になる
- **チーム力**：先発のポジション適性、調子、コンディション、選手間の連携、フォーメーションの熟成度、合宿テーマで決まる
- **試合エンジン**（`js/engine.js`）：中盤の力で支配率、攻撃力と相手の守備・GKでシュートの質が決まる。体力の消耗、警告・退場、負傷、PK、セットプレー、延長・PK戦あり

```
index.html          画面

js/world.js         クラブ事情・シーズン成績・負傷・移籍

js/media.js         メンバー発表・記者会見・報道

js/ranking.js       FIFAランキング
js/life.js          選手からの相談・家族の事情・コンビ・プレッシャー・前日会見・天候と審判
js/depth.js         相手国の事情・戦術の研究・声かけ・性格・大会前の準備・通算記録・観客・強化予算・育成年代
js/extra.js         クラブ交渉・移動と気候・主将・二重国籍・協会との面談・分析の重点
js/game.js          進行・育成・大会
js/ui.js            描画と操作
tools/sim-test.js   バランス検証と通しプレイテスト（node tools/sim-test.js 20）
```

選手の能力値・所属はゲーム用の推定であり、実在選手の公式評価ではありません。
